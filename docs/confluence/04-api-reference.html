Kody odpowiedzi

KodOpis
200OK — operacja zakończona sukcesem
201Created — zasób utworzony
400Bad Request — błąd walidacji (Zod)
401Unauthorized — brak/niepoprawny token
403Forbidden — brak uprawnień (RLS / rola)
404Not Found — zasób nie istnieje
429Too Many Requests — rate limit (100/15min)
500Internal Server Error — logowane do Sentry
