3. Konfiguracja Supabase

a) Utworzenie bazy danych

  1. Zaloguj się na supabase.com i utwórz nowy projekt.
  2. Skopiuj URL, anon key i service role key z Settings → API.

b) Inicjalizacja schematu

Wykonaj cały plik supabase/schema.sql (v3.0, 787 linii) w SQL Editor:

sql

c) Konfiguracja Auth

  1. Authentication → Providers → Email: włącz Confirm email
  2. Authentication → Providers → GitHub: dodaj Client ID/Secret z GitHub OAuth App
  3. Authentication → Providers → Google: dodaj Client ID/Secret z Google Cloud Console
  4. Authentication → URL Configuration → Site URL: http://localhost:3000 (dev) lub URL produkcyjny
  5. Authentication → URL Configuration → Redirect URLs: dodaj http://localhost:3000/auth/callback
