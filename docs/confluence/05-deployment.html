Deployment & DevOps

Opcja 1: Vercel (rekomendowana)

Vercel to natywna platforma dla Next.js — zero-config deployment z edge functions, preview per PR i auto-scaling.

Krok po kroku

  1. Połącz repozytorium Git z vercel.com
  2. Framework Preset: Next.js (auto-detect)
  3. Root Directory: ./ (domyślne)
  4. Dodaj zmienne środowiskowe (wszystkie 10 z .env.example) w Settings → Environment Variables
  5. Deploy — Vercel automatycznie wykona npm run build

Konfiguracja domenowa

  1. Settings → Domains → dodaj domenę
  2. Zaktualizuj NEXT_PUBLIC_APP_URL
  3. Zaktualizuj Supabase Auth → URL Configuration → Site URL + Redirect URLs

Preview Deployments

Każdy PR generuje unikalne preview URL. Zmienne środowiskowe preview można ustawić oddzielnie (scope: Preview).
