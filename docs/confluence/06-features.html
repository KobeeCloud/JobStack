4. AI-powered sugestie

  • Optymalizacja kosztów — AI analizuje diagram i sugeruje tańsze instancje/regiony
  • Best practices — rekomendacje HA, DR, security
  • Auto-fix compliance — AI proponuje zmiany naprawiające znalezione naruszenia
  • Natural language → diagram — opisz infrastrukturę słownie, AI generuje węzły i połączenia
  • Model: GPT-4 Turbo (OpenAI SDK v6)
  • Bezpieczeństwo: AI otrzymuje tylko metadane komponentów, bez credentiali

5. Kalkulator kosztów

  • Dynamiczne ceny per typ instancji, region i provider
  • Szacunki monthly + yearly (z discountem za Reserved Instances)
  • Wykresy porównawcze (Recharts) — bar/line chart per komponent
  • Eksport do CSV/PDF

6. Szablony infrastruktury

  • Biblioteka predefiniowanych szablonów (3-tier web app, microservices, serverless...)
  • Szablony publiczne (community) i prywatne (per organizacja)
  • One-click deploy do nowego projektu
  • Analityka użycia szablonów (template_usages)

7. Zarządzanie organizacjami

RolaUprawnienia
OwnerPełna kontrola — billing, usuwanie, zarządzanie członkami
AdminZarządzanie projektami i członkami
MemberTworzenie i edycja projektów
ViewerTylko odczyt — przeglądanie projektów i diagramów
  • Zaproszenia email z tokenem (7 dni ważności)
  • Strona akceptacji zaproszenia: /invites/accept/[token]
  • Tworzenie organizacji z rollback (jeśli dodanie ownera się nie powiedzie)

8. Historia wersji diagramów

  • Automatyczny zapis wersji przy każdym PUT /api/diagrams/[id]
  • Panel VersionHistory w edytorze (sidebar)
  • Przywracanie dowolnej wcześniejszej wersji
  • Metadane: autor, timestamp, opis zmian

9. Udostępnianie projektów

  • Udostępnianie per użytkownik: view / edit / admin
  • Dialog ProjectShareDialog z wyszukiwaniem użytkowników
  • Sprawdzanie verify_project_access() (funkcja DB) przy każdym request

10. Webhooks

  • Użytkownicy mogą skonfigurować webhooki (URL + secret) w Settings
  • Eventy: project.created, project.updated, diagram.saved, export.completed, compliance.scanned
  • HMAC-SHA256 signing z user secret
  • Panel zarządzania w /settings → zakładka Webhooks

11. i18n (wielojęzyczność)

  • Obsługiwane języki: Polski (PL), English (EN)
  • next-intl z plikami messages/pl.json i messages/en.json
  • LanguageSwitcher w Navbar
  • Consent GDPR wielojęzyczny na stronie rejestracji

12. Interaktywna strona demo

  • Ścieżka: /demo
  • Read-only React Flow z przykładowym diagramem
  • Bez wymagania logowania — do prezentacji produktu
