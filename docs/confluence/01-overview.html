Czym jest JobStack?

JobStack to platforma do wizualnego projektowania infrastruktury chmurowej (AWS, Azure, GCP, Kubernetes) z drag-and-drop edytorem diagramów, wbudowanym AI, skanowaniem compliance, testowaniem infrastruktury i eksportem do Terraform/CloudFormation/ARM/Pulumi.

Bezpieczeństwo

  • RLS (Row Level Security) — na wszystkich 16 tabelach
  • Rate Limiting — Redis (100 req/15min/user)
  • CSP — Content Security Policy w next.config.ts
  • GDPR — eksport danych, usuwanie konta (7-day grace), consent i18n
  • Weryfikacja email — wymuszana przez middleware
  • API — OpenAI nie otrzymuje danych wrażliwych (tylko metadane komponentów)
